# jessicastockdale.github.io — Quarto site

This is a [Quarto](https://quarto.org) website project. Page content is Markdown (`.qmd` files), and various components are defined in `_quarto.yml`.


## Publishing to GitHub Pages

Quarto can publish directly:

```         
quarto publish gh-pages
```

This builds the site and pushes it to a `gh-pages` branch, which GitHub Pages serves automatically.
